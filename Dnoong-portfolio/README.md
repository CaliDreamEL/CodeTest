# DNOONG 摄影作品集

这是一个无需安装依赖的静态网站。直接双击 `index.html` 即可预览。

## 添加作品

在首页底部点击“管理作品”，或直接打开 `manage.html`。选择照片，填写中文标题、英文标题、分类和年份后点击“保存到作品集”。保存后回到首页刷新即可看到新作品。

## 编辑内容

打开 `content.js`：

- `projects`：添加、删除或替换作品，`image` 支持本地图片路径（例如 `assets/photo-01.jpg`）。
- `profile`：修改个人简介和信息。
- `contact`：修改邮箱和社交链接。

当前图片使用 Unsplash 作为展示占位图。正式发布前建议换成自己的高分辨率照片，并统一压缩为 WebP。

新增作品会保存在当前浏览器的本地数据中；这是一套轻量管理入口，不是带账号的云端后台。
